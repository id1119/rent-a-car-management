# Rent-a-Car Management System

A Java application for managing core rent-a-car workflows, structured around domain logic, specifications and automated tests.

## Highlights

- Modular application structure
- Separation between source code, specifications and tests
- Scripted test execution
- File-based project data
- IntelliJ-based Java project setup

## Project structure

```text
src/             # Application source code
test/            # Automated tests
specifications/  # Project requirements/specifications
data/             # Application data
lib/              # Project dependencies
run_tests.sh      # Test runner
```

## Running tests

```bash
./run_tests.sh
```

## Tech stack

- Java
- Shell scripting
- Automated testing

## Status

Academic software-engineering project demonstrating structured requirements, implementation and testing of a rent-a-car domain application.
